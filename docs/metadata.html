Congressional Correspondence Metadata Documentation

Author

Devin Judge-Lord

1. Overview

This dataset combines congressional correspondence, inquiries, casework, referrals, and related metadata received from approximately 100 federal agencies, offices, commissions, and government-related entities.

The merged dataset contains records from multiple source systems. Because agencies used different correspondence management systems, exported files contain many overlapping fields with different names. After merging, the dataset contains 700+ raw metadata columns, many of which represent the same or similar concepts.

Examples include:

  • DATE, Date Received, Receive Date, Received.Date, DATEREC
  • FROM, From, Correspondent, Constituent, Originator
  • SUBJECT, Subject, Issue, Topic, Description
  • Control, Control Number, Control No., Case Number, Tracking Id
  • Due, Due Date, Date Due, Suspense Date, Response Due Date

For a list of all fields see Section 9.

To support analysis, the project preserves raw fields while creating a documented crosswalk from agency-specific source columns to standardized canonical variables.

2. Dataset

Each row represents one correspondence-related record as provided by a source agency, such as

  • Congressional inquiry
  • Constituent casework referral
  • Oversight or policy correspondence
  • Request for information

5. Raw Metadata Columns

The merged dataset includes 700+ raw metadata fields. These fields were retained to preserve the original source information from agency FOIA responses.

Raw fields include:

  • Source identifiers
  • Case numbers
  • Control numbers
  • Tracking numbers
  • Received dates
  • Due dates
  • Closed dates
  • Response dates
  • Routing information
  • Staff assignments
  • Congressional offices
  • Committees
  • Subject, topic, or issue fields
  • Correspondent and constituent fields
  • Notes/status fields
  • Document type and correspondence type fields
  • Agency-specific workflow fields

For a list of all fields see Section 9.

Many raw fields are sparse because they only apply to one agency or one export format.

6. Metadata Coverage Counts

A field coverage table vars_by_agency.csv provides counts non-missing values for each metadata column within each agency.

Each row in the coverage table represents one agency.

Each column after agency represents a metadata field.

Each cell contains:

The number of records for that agency where the field is not missing.

For example:

agency ID DATE FROM SUBJECT
ABMC 87 87 87 87
Amtrak 1571 1571 1571 0
DHHS_CMS 69938 69938 69938 69937

Interpretation:

  • A count of 0 means the field is absent or fully missing for that agency.
  • A count equal to the agency row count means the field is populated for all records from that agency.
  • Partial counts indicate incomplete coverage.

7. Field Consolidation Strategy

Because many fields represent the same concept under different names, the project uses a crosswalk table to map raw agency-specific fields to canonical variables.

The guiding principle is:

Preserve all raw source fields, but create standardized canonical fields for analysis.

This allows analysts to:

  1. Use harmonized variables where possible.
  2. Trace every standardized value back to its source column.
  3. Retain agency-specific fields for auditing or specialized analysis.
  4. Avoid irreversible data loss during cleaning.

library(readr)
library(dplyr)
library(tidyr)
library(stringr)

# -----------------------------
# Input / output files
# -----------------------------
input_file <- here::here("vars_by_agency.csv")

output_summary <- "agency_specific_fields.csv"
output_counts  <- "agency_specific_fields_with_counts.csv"
output_single  <- "single_agency_fields.csv"
output_subset  <- "subset_specific_fields.csv"

# -----------------------------
# Read coverage table
# -----------------------------
coverage <- read_csv(input_file, show_col_types = FALSE)

agency_col <- "agency"

if (!agency_col %in% names(coverage)) {
  stop("Expected an 'agency' column in the coverage table.")
}

# -----------------------------
# Helper: detect placeholder/import artifact columns
# -----------------------------
is_placeholder_field <- function(x) {
  x_norm <- x |>
    str_replace_all("\u00a0", " ") |>
    str_trim()

  x_lower <- str_to_lower(x_norm)

  str_detect(x_lower, "^x\\d+$") |      # X1, X32, x17
    str_detect(x_lower, "^\\.\\.\\.\\d+$") | # ...21, ...36
    str_detect(x_lower, "^field\\d+$") |     # Field1, Field2
    str_detect(x_lower, "^blank$") |         # Blank
    str_detect(x_lower, "^s$") |             # s
    str_detect(x_lower, "^n$") |             # n
    str_detect(x_lower, "^nn$")              # nn
}

# -----------------------------
# Convert to long format
# -----------------------------
coverage_long <- coverage |>
  pivot_longer(
    cols = -all_of(agency_col),
    names_to = "raw_field",
    values_to = "non_missing_count"
  ) |>
  mutate(
    non_missing_count = suppressWarnings(as.numeric(non_missing_count)),
    non_missing_count = replace_na(non_missing_count, 0),
    is_placeholder = is_placeholder_field(raw_field)
  ) |>
  filter(!is_placeholder)

# -----------------------------
# Count number of agencies
# -----------------------------
n_agencies <- coverage |>
  distinct(.data[[agency_col]]) |>
  nrow()

# -----------------------------
# Create agency/subset-specific field summary
# -----------------------------
agency_specific_fields <- coverage_long |>
  group_by(raw_field) |>
  summarise(
    n_agencies_with_data = sum(non_missing_count > 0),
    agencies_with_data = paste(
      .data[[agency_col]][non_missing_count > 0],
      collapse = "; "
    ),
    total_non_missing = sum(non_missing_count),
    .groups = "drop"
  ) |>
  filter(
    n_agencies_with_data > 0,
    n_agencies_with_data < n_agencies
  ) |>
  arrange(n_agencies_with_data, raw_field)

# -----------------------------
# Write summary table
# -----------------------------
write_csv(agency_specific_fields, output_summary)

fields_to_keep <- agency_specific_fields$raw_field

agency_specific_counts <- coverage |>
  select(all_of(agency_col), all_of(fields_to_keep)) |>
  pivot_longer(
    cols = -all_of(agency_col),
    names_to = "raw_field",
    values_to = "non_missing_count"
  ) |>
  mutate(
    non_missing_count = suppressWarnings(as.numeric(non_missing_count)),
    non_missing_count = replace_na(non_missing_count, 0)
  ) |>
  pivot_wider(
    names_from = all_of(agency_col),

  left_join(
    agency_specific_fields |>
      select(raw_field, n_agencies_with_data, total_non_missing),
    by = "raw_field"
  ) |>
  relocate(
    raw_field,
    n_agencies_with_data,
    total_non_missing
  ) |>
  arrange(n_agencies_with_data, raw_field)
